# 刘权益SKILL

> 创建: 2026-09-09 (用户要求: "其他都不要, 只要总权益, 那个金额就好")
> **更新: 2026-09-17 (用户指令: "两个都出, 再加未实现盈亏")** ——
> 原版只出总权益, 用户看不出"落袋多少 vs 浮动多少"; 现改为三行(钱包余额 / 未实现盈亏 / 总权益)。
> 适用目录: `/home/myuser/websocket_new/` (earth-1.0 仓库)

## 一键执行

```bash
cd /home/myuser/websocket_new && python3 .agents/skills/liu-equity/equity.py
```

## 输出规范

**固定三行**(便于竖读对照):

```
钱包余额     1,308.25U ≈    8,794.43 CNY   (已实现, 不随行情波动)
未实现盈亏     +37.37U
总权益       1,345.61U ≈    9,045.61 CNY   (rate 6.7223)
```

| 行 | 字段 | 含义 |
|---|---|---|
| 1 | **钱包余额**(`totalWalletBalance`) | **已落袋的钱** —— 只有平仓才变, 不随行情波动 |
| 2 | **未实现盈亏**(`totalUnrealizedProfit`) | 当前全部持仓的**浮动**盈亏, 随时变 |
| 3 | **总权益**(`totalMarginBalance`) | = 钱包余额 + 未实现盈亏 |

- **恒等式**: 总权益 = 钱包余额 + 未实现盈亏(可自校验)
- 汇率: open.er-api.com 主源, frankfurter.app 备源; 双源失败则只出U并标注
- 未实现盈亏**不折人民币**(它是浮动的, 折算会给人"已到手"的错觉)
- **不附持仓明细、不附浮盈分解、不附分析建议**
- 用户若追问细节, 再另行执行 `python3 audit/hybrid_live.py status` 或持仓查询

## 数据口径

- 来源: HYBRID_BINANCE 凭证 → `fapi.binance.com/fapi/v2/account`
- 与 `audit/hybrid_live.py status` 的"总权益/钱包/未实现"同源, 逐位一致
- 实时值, 无缓存
