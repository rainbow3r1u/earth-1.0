# 模型水准测评 SKILL

> 创建: 2026-09-13 (用户指示"做个skill叫模型水准测评", 并把当天的逻辑推理固化下来供以后复查)
> 适用目录: `/home/myuser/websocket_new/` (earth-1.0 仓库)

## 0. 一句话

把"模型还行不行"拆成**六层可测量判读**。每层都必须回答同一个问题的两半：
> **这是模型的事，还是行情的事？**

---

## 1. 怎么触发（用户只需说一句话）

> **用户说「模型水准测评」→ 直接执行全流程 → 汇报结论。用户不需要记任何命令或参数。**

本 SKILL 的动作就一条：运行 `scripts/model_quality_audit.py`（**不带任何参数**），一次给出两部分：

```
第一部分: 六层判读(①身份 ②能力 ③供给 ④捕捉 ⑤结构 ⑥金矿格) + 综合判定
第二部分: 长窗口复盘(默认60天窗口) —— 四条结构性证据
```

汇报时按 §6 输出规范整理（结论先行、每层给「读数 + 判据 + 归属」）；
**不要把命令原样丢给用户**，直接给结论。

> 内部参数（仅当 agent 需要聚焦时用，不写进给用户的回复）：`--review N` 只看复盘并指定天数；`--json` 结构化。

## 2. 六层原理与判读线（核心知识，勿重复推导）

### ① 身份层 —— 模型有没有被改过

- **原理**：冻结一份特征输入（`data/pred_feats_2026-09-13.npz`，MD5 `06a94b3be2db`，**永不改变**），
  每天用当日 SOUP 模型对它推理 → 概率向量记入账本。**输入固定 ⇒ 输出变化只能来自模型本身。**
- **判据**：ρ≥0.85 正常 / 0.5~0.85 需查 / **<0.5 模型已实质改变**
- **实测基线（9/09~9/13）**：ρ 均值 **0.9939**，最低 0.9921 → 每日全量重训的固有漂移仅 **0.6%**
- **异常时动作**：`python3 scripts/prod_fingerprint.py --diff` → 定位是**代码/模型/训练数据/掩码/外部数据**哪一项变了
- **为什么不用模型文件比对**：pkl 只留 5 天且从不入 git（仓库外目录 + `.gitignore` + 同步排除扩展名）；
  COS 备份用**固定 key** 且 bucket **无版本控制** → **8/03 的模型已永久丢失**（2026-09-13 实测）。
  已改日期化归档（`scripts/cos_model_archive.py`，`klines/cache/models/xgb_daily_{long,short}_YYYYMMDD.pkl`）
- **⚠️ 关键约束：标尺只认固定输入。** 实测对照：固定输入逐日 ρ=0.994；而生产预测逐日（输入每日在变）ρ 仅 **0.65**（0.24~0.88）
  → **用变化的输入无法区分"数据变了"与"模型变了"**

### ② 能力层 —— 相对能力（lift）

- **定义**：`lift = 顶部命中率 ÷ 宇宙底率` = 我们的榜单比"随机抓一个币"强多少倍
- **判据（用该档自身全期基线当尺子，不共用绝对阈值）**：
  `≥×0.8 → ✅完好` / `×0.65~0.8 → 🟡观察` / `<×0.65 且供给已恢复 → 🔴退化`
- **实测锚点**：全期（8/03~9/10，39窗口/390笔）lift **3.73x**；近7窗口 **5.27x = 141%** → 完好
- **为什么这样判**：lift 的分子分母同受行情影响 → **它与行情相对无关，所以它掉了才是模型的事**

### ③ 供给层 —— 市场给不给（宇宙底率）

- **定义**：底率 = 全宇宙约 540 币中，2 日涨幅 ≥+33% 的占比
- **分档标尺（8/03~9/10，39天/390笔，影子主臂 LONG，300U 名义）**：

| 档位 | 天数/笔数 | 批次合计 | 每笔均值 | **每笔中位** | **剔TOP3后** | **到期单均** |
|---|---|---|---|---|---|---|
| **荒 <1.0%** | 12天/120笔 | **−470U** | −3.92 | **−9.43** | −10.24 | +30.06 |
| **偏紧 1.0~1.5%** | 10天/100笔 | −148U | −1.47 | **−6.65** | −8.49 | +34.57 |
| **正常 ≥1.5%** | 17天/170笔 | **+3186U** | +18.74 | **+12.31** | **+6.05** | **+106.36** |

- **读法（稳健性检验后确立）**：排序三列一致 → 结论稳健；**但均值被尾部拉高**
  （正常档均值 +18.74U 中前 3 天就贡献 +233.8U，剔掉只剩 **+6.05U**）
  → **常态看中位/剔尾；判断"当期亏损是否正常"要拿中位列比**（荒年中位 −9.43 比均值 −3.92 更差）
- **分布参考**：25分位 0.93% / 中位 1.48% / 75分位 1.85% / 最低 0.37% / 最高 9.26%
- **⚠️ 用途边界**：底率是**同窗口事后量**（要 T2 收盘才结算得出），**入场那天不知道今天的底率**
  - 实测：同窗口底率 vs 当日每笔U **r=+0.266**（诊断力强）；**入场前可见底率 r=+0.046**（日级预测力≈0）
  - **→ 正确用途 = 诊断 + 状态判定，不是"今天开不开仓"的闸门**

### ④ 捕捉层 —— 抓到多少 / 够不够肥

- **命中率的分母只有 10 个选币** → 单日只能取 0%/10%/20%…（**10.00% = 恰好 1 个币**，不是"稳定 10% 概率"）
- **结构门槛（关键）**：300U 名义下 1 笔 +33% ≈ **+99U**；当日其余 9 笔若止损（SL-5% 每笔 −15.5U）= **−139.5U**
  → **只抓到 1 个 +33% 不足以让当日转正，尾部需 ≥+47%（≈+140U）**
- 所以要看的不只是"抓到几个"，更是**尾巴够不够肥**（到期单均 vs 同档基准）

### ⑤ 结构层 —— 出场结构优劣有没有变

- **2×2 受控对照**（同源同日、变量隔离）：SL5/SL8 × 48h/72h，看**每笔U 排序是否稳定**
- **实测（8/03~9/12）**：基线 +6.41 → SL-8%/48h +6.92（**+8%**）→ SL-5%/72h +12.17（**+90%**）→ SL-8%/72h **+13.66（+113%）**
- **结论：收益提升几乎全部来自"持有时长 48h→72h"（+90%），放宽止损只是次要放大器（+8%）**
- 机理：72h 让到期单均 +45.22→+76.03U（右尾变肥）；48h 下单纯放宽止损只是把更多单拖到终点却让到期单均反降
- **排序变化 = 结构结论动摇的信号** → 需复查 2×2

### ⑥ 金矿格 —— C远×V高

- **定义**：昨日完整 bar 成交额在自身**前20根完整 bar** 中的分位 **>0.70**（V高）**且** 距 20 根最低点（entry=当日开盘）**>33%**（C远）
- **无前视**：只用已收盘 bar，08:21 即可算出
- **历史依据**：格内 15% 的笔数贡献 **81%** 的 LONG 盈利（影子 SL8/72h 归因：+74.35U/笔 vs 格外 +3.09U/笔）
  —— **但回测 t=1.23 未显著**（前视版曾误报显著，已被证伪）→ 现在**只提醒不干预**，等 10/23 终审的前向样本
- 晨报 3.5 节顶部**永远有一行心跳**（格内 0 时显示最接近候选 + 差在哪条腿）

## 3. 综合判定的逻辑（回答"模型还行不行"）

```
① 身份层异常                        → 模型被改过 → 查指纹账本定位(代码/模型/数据)
② 能力层掉了 且 ③ 供给已恢复正常      → 模型退化   → 才需动模型层
② 能力层正常 而 当期在亏             → 归因于 ③ 供给(荒/偏紧) → 无需干预
⑤ 结构层排序变化                     → 结构结论动摇 → 复查 2×2
④ 到期单均长期低于同档基准            → 右尾捕捉有问题(但先排除供给因素)
```

**证伪线**：**底率回到 ≥1.5%（正常档）而 lift 掉到自身基线 ×0.65 以下 → 模型退化**，才动模型层。
**铁律：右尾能力看这三层（lift / 底率 / 命中率），不看 IC。**
实测：9/06 IC_L=−0.149 而 lift=9.1x；9/07 IC_L=−0.186 而 lift=13.7x（**IC 深负但顶部照样抓到**）
→ 与已验证的 8/19、8/25、8/28 三条脱锚同型。**IC 是体制解读器，不是闸门。**

## 4. 长窗口复盘（自动附带的第二部分；回答「两个月了，模型还行不行？」）

> 这部分**每次测评都会自动输出**（默认 60 天窗口），不需要用户额外要求或输入参数。
>
> **核心原则: 复盘只看结构性证据 —— 盈亏是结果(受行情影响), 四条证据才是原因(归模型)。**
> **绝不要**用"这两个月赚/亏了"直接判模型好坏。

### 四条结构性证据（★ = 用户 2026-09-13 明确要求纳入复盘）

| # | 看什么 | 健康区间 | 不健康意味着 |
|---|---|---|---|
| **① ★ lift**(模型相对能力) | **≥ 自身基线 ×0.8** | 掉到 ×0.65 以下 **且供给已恢复** → 模型退化 |
| **② ★ 到期单均** | 落在**同档**基准内（荒 +30 / 偏紧 +35 / 正常 +106U） | 长期低于同档 → 右尾捕捉有问题（先排除供给） |
| **③ ★ 2×2 四档排序** | **SL-8%/72h > SL-5%/72h > SL-8%/48h > SL-5%/48h** 未变 | 排序变化 → 结构结论动摇，需复查 2×2 |
| **④ ★ 底率档位分布** | 正常档(≥1.5%)占比不低（<30% 即供给不足） | 供给不足 → **期间盈亏走平不算模型问题** |

### 为什么必须是这四条（而不是盈亏）

实测（8/03~9/12，41 天）：利润的 **90% 来自最肥的 5 天**（8/07 +239.7U/笔、8/25 +138.2U/笔…）。
→ **一个两个月窗口里如果没出现大尾巴（底率长期荒/偏紧），账户会走平而模型完全健康。**
→ 只看盈亏会**误杀好模型**；只看模型会**无视行情**。所以复盘必须把"原因"和"结果"分开看。

### 复盘的三个陷阱（已实测踩过）

1. **窗口 = 全部历史时，① 的比值恒为 100%**（没有更早的基线可对照）→ 输出会标 `此时①无判别力`，
   需等样本积累超过窗口长度后该比值才有意义
2. **② 必须与"窗口自己的档位"对应的基准比**，不能跨档比（荒年 +30U 和正常期 +106U 是同一指标的不同档）
3. **④ 的档位划分用"窗口内逐日底率"**，不是窗口平均底率 —— 平均 1.5% 可能由"一半荒年 + 一半正常"构成

### 复盘输出样例（2026-09-13 实测，39 天窗口；实际输出自动附在六层之后）

```
① lift 3.73x vs 自身基线 3.73x = 100%   ⚠️窗口=全历史, 无判别力
② 到期单均 +54.66U (190笔) | 窗口平均底率 1.65% → 正常档(基准+106U)
③ SL-5%/48h +6.58 → SL-8%/48h +7.04 → SL-5%/72h +12.74 → SL-8%/72h +14.05   ✅排序未变
④ 荒 30.8%(-6.64U/笔) | 偏紧 25.6%(+8.73U) | 正常 43.6%(+31.78U)   ✅供给正常
结论: 四条均未见异常 → 期间盈亏归因于行情供给, 非模型问题
```

## 6. 输出规范

- **结论先行、表格优先**，每层给"读数 + 判据 + 归属（模型/行情）"
- 不打无触发器的时间预测
- 涉及"要不要改模型"的结论**必须给证伪线**
- 用户若问"是不是模型坏了"，先用本 SKILL 跑一遍再回答 —— 不要凭连亏天数下结论（§0.5 公理4）
- 汇报时**两部分一起给**: 先六层(现状), 后复盘(长窗口四条证据); 若四条均正常, 明确说「盈亏归因于行情」,
  不要说「模型还行但最近运气差」这类含糊话
