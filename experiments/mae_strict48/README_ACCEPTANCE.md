## 2. 离线复验闸门（GPU 服务器, CPU 12 核）

### A. 数据/标签审计（不通过不训练）
- 500 币 1m .bin 连续性 0 缺口/0 重复/0 非法 OHLC；
- 标签总数与 Earth 2.0 底率一致（全时段约 456,818 行）；
- 本机 Python labeler 与 Rust labeler 抽 1000 条对照: 未解释差异必须 = 0。

### B. MAE 可预测性复验
- 训练 ≤2026-03-31, 验证 2026-04-01 ~ 08-05, 严格无泄漏（训练 ts ≤ 预测日-3）;
- LONG BSS ≥ +0.25, SHORT BSS ≥ +0.25（Earth 2.0 报告值 0.41/0.40）;
- 验证集按 P(MAE>5%) 中位数分层后, 保留半边的 MAE>5% 比例 ≤ 20%。

### C. 最终配置 4 段 walk-forward
- 段: 2025-06~09 / 2025-10~2026-01 / 2026-02~05 / 2026-05~08;
- 每段必须: 扣费后净 PnL > 0、胜率 ≥ 65%、stop 率较无过滤降低 ≥ 30%;
- 4 段中不得有 2 段及以上失败; 任何一段累计 < 0 即否决上线。

### D. 成本敏感性（非调参, 只验证鲁棒性）
- 滑点 ×1/×2/×3、手续费 ×2 三种压力下, C 闸门仍通过;
- 任一压力场景失败 → 进入影子盘观察, 不直接上线。
