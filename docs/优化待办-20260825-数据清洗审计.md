- 8/18-20 暴拉期梯度完全倒挂（8/19 尾部 +11.97% vs 头部 +0.86%）——**轮动补涨行情，模型排序编码动量风格，反向挨打**

## P0：训练/推理不对称（唯一"预期必然为正"项）

**问题**：预测端剔除 5 日均成交额 <500,000U 的币（`auto_dual_trade.py:2020` MIN_VOLUME_24H），但**训练集零过滤**——日均 1 万 U 的死币照样参与训练。模型在低流动性分布上学到的模式，实盘永远用不到；高流动性币的样本被噪声稀释。回测无法暴露（回测执行过滤与生产一致，训练侧同样不过滤）。

**改法**：训练样本构建时加同款过滤（样本日的前 5 日均成交额 ≥500,000U 才入训练集）。
**验证**：GPU 180d A/B（gpu_backtest_exp.py 加 VOLUME_FILTER 臂，照 MIN_KLINES 模式）。预期样本量 -30% 左右，Sharpe 持平或升。
**位置**：`auto_dual_trade.py` 阶段2样本构建循环（L851 起）+ `gpu_backtest_exp.py` 同源段。
**注意**：MIN_VOLUME_24H=500000 本身无实验背书（拍脑袋值），A/B 时顺带做 30 万/50 万/100 万三档敏感性。

## P1：OI 特征半程失明

**问题**：`fetch_oi_for_symbols` 只取最近 90 个 OI 快照（`auto_dual_trade.py:783` 的 `[:90]`），但训练窗 180 天 → 前半程样本 oi_chg 恒为 0，且"缺数据"与"OI 真没变"不可区分。oi_daily.json 本身是累积合并的（历史更长），截断疑似 Binance API limit=90 的被动继承，无注释无实验。

**改法**：放开 `[:90]` 截断，取全量历史。
**验证**：GPU 180d A/B（注意 oi_chg 特征分布前后对比，确认前半程不再恒零）。
**风险**：低——纯数据覆盖扩展，不动任何逻辑。

## P2：缺失值语义混淆（宏观特征周末归零）

**问题**：宏观/板块/ETF/费率缺失一律填 0（`daily_predictor.py:527-552`，无 ffill），NaN 也填 0。SP500/DXY 每个周末整列变 0 → "无数据/中性/零收益"三态不可分。
**用户澄清（2026-08-26）**：SP500/DXY 周末缺失是**休市事实**，不是数据缺失——周末本就没有交易。填 0 的问题不是"数据丢了"，而是"休市（应延续周五收盘状态）"和"宏观真崩了（0）"两个语义被压成同一个值，模型无法区分。

**改法**（二选一，A 成本低）：
- A：缺失时 ffill 前值（周末宏观=周五收盘值）
- B：加缺失指示位特征（维度 946→+宏观组数量，涉及 EXPECTED_N 断言，改动大）

**验证**：GPU 180d A/B（MACRO_FFILL 臂）。
