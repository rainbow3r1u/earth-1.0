8. **Earth-1.0 终版冻结**：8/7。
9. **Earth-2.0 Rust 严格 48h 预测器**：8/8-8/10 立项、组件开发、特征逐位对照、复刻、实验。

## 3. 已验证 / 必须保留的规则

- 特征列分区前必须拷贝（幽灵修复）。
- 回测特征必须与生产同源（`adt._build_feat_impl`）。
- 入场日不豁免止损扫描；结算 T+2 后，`cutoff=今日-3 UTC`，先损后盈。
- Perm Test 必须在 SOUP 平均后，使用同一概率输入。
- ETF 取最后一列 `Total`；数据不足置零，满 180 天再启用。
- 宏观资产不得静默丢弃（重试 3 次 / 保留陈旧 / 拒写 + 告警）。
- SHORT 开仓禁用，持仓管理 LONG-only。
- Python 做实验，Rust 只移植已验证设计。

## 4. 已证伪 / 已废弃（不要重蹈）

- 8/4 ETF 取第 2 列 `IBIT`：错误，已回滚。
- 旧结算口径：T+2 08:05 快照、入场日豁免、5 分钟 open 快照：已废弃。
- SHORT 直接开仓：已禁用（前向 + 1m 回溯证明止损不可控）。

- Earth-2.0 的 M5 等闸门实验：已有证伪结论（见 `m5_result.md`）。
