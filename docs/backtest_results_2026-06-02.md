### 止损/止盈逻辑 (真)

```
持仓期间逐日检查:
  做多: Day1 最低价 ≤ 止损价 → -10% 退出
        Day1 最高价 ≥ 止盈价 → +10% 退出
        都未触发 → Day2 同样检查
        都未触发 → Day2 收盘价平仓

  做空: Day1 最高价 ≥ 止损价 → -10% 退出
        Day1 最低价 ≤ 止盈价 → +10% 退出
        同上
```

这是唯一与生产 Algo Order (CONDITIONAL STOP_MARKET/TAKE_PROFIT_MARKET) 行为对齐的回测。

## 五、结论

1. **clean 365d 是唯一可信的长期回测**: +549%/Sharpe 4.75，真止损止盈对齐生产
2. **拉长时间后模型衰减**: 50 天 Sharpe 16.20 → 365 天 Sharpe 4.75，止盈截断 + 市场结构变化
3. **伪止损虚高严重**: 旧版 +3557% vs 真止损版 +549%，差额来自无止盈 + 亏损截断偏差
